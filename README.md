# Username Validation

A Python exercise focused on validating usernames. The implementation is in `check.py`.

## Requirements
- Python 3.8 or later

## Run
```bash
git clone https://github.com/dperry713/username-validation.git
cd username-validation
python check.py
```

Follow any terminal prompts provided by the script.

## Project structure
- `check.py` — username validation logic.

## Development
Document the accepted username format and keep validation rules explicit. Test valid values, invalid characters, boundary lengths, empty input, and whitespace handling. Apply server-side validation when integrating this logic into an application.
